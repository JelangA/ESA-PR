# Enterprise Software Architecture

Repository ini digunakan untuk menyimpan seluruh tugas mata kuliah **Enterprise Software Architecture**.  
Setiap tugas dipisahkan menggunakan branch yang berbeda agar pengelolaan source code lebih rapi, terstruktur, dan mudah dikembangkan.

---

## 📂 Struktur Branch

| Branch | Deskripsi |
|--------|------------|
| `main` | Branch utama repository |
| `tugas-1` | Implementasi tugas 1 |
| `tugas-2` | Implementasi tugas 2 |
| `tugas-3` | Implementasi tugas 3 |
| `...` | Dan seterusnya |

---

## 🚀 Clone Repository

```bash
git clone <url-repository>
cd <nama-repository>
```

---

## 🌿 Melihat Daftar Branch

```bash
git branch -a
```

---

## 🔄 Pindah ke Branch Tugas

Contoh pindah ke branch tugas 1:

```bash
git checkout tugas-1
```

atau:

```bash
git switch tugas-1
```

---

## ➕ Membuat Branch Tugas Baru

Contoh membuat branch baru untuk tugas berikutnya:

```bash
git checkout -b tugas-4
```

atau:

```bash
git switch -c tugas-4
```

---

## 📌 Aturan Penamaan Branch

Gunakan format berikut:

```text
tugas-[nomor]
```

Contoh:

```text
tugas-1
tugas-2
tugas-3
```

Jika diperlukan branch tambahan:

```text
feature/nama-feature
fix/nama-perbaikan
```
